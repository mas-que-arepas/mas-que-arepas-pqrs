MAS'QUE AREPAS - SISTEMA PQRS
Versión demo funcional.

1. Abre index.html en un navegador.
2. Registra una PQRS y recibirás un radicado MQA-000001.
3. Ve a admin.html.
4. Contraseña DEMO: MQA2026
5. Las PQRS de esta versión se guardan en el navegador mediante localStorage.

IMPORTANTE: esta versión sirve para demostración/prototipo. Para uso real con clientes desde cualquier celular se debe conectar a una base de datos y publicar el sitio en Internet. No uses la contraseña demo en producción.
